# InternAgents

[中文](README.md) | [English](README.en.md)

InternAgents is an agent workspace developed by Shanghai Artificial Intelligence Laboratory for research, learning, and technical exploration. It helps users work with workspace files for reading, summarization, analysis, generation, and human-approved actions.

## User Manual Website

A standalone Chinese user manual website is available here:

[Open the InternAgents User Manual](https://shuyuehu.github.io/InternAgents/)

The website covers the workspace, task tutorials, file preview, conversation management, attachments, configuration, skills, approval, and common questions.
